# Ev Bot (Home Assistant eklentisi)

Telegram ev botu. Cenk'in bota yazdığı her mesajı Claude Code'a verir, cevabı aynı sohbete yazar;
Home Assistant'ı Supervisor API üzerinden yönetir. Şahsi proje.

- Depo: `/share/ev-otomasyon` (scp ile kopyalanır; eklenti depoyu çekmez)
- Seçenekler: Telegram bot token, sohbet id, Claude OAuth token (claude.ai aboneliği)
- Kalıcı veri: `/data` (durum, Claude oturumları, günlükler)
